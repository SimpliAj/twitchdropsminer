About Twitch Drops Miner

This application automatically mines timed Twitch drops without downloading stream data.

How to Use

  1. Login using your Twitch account (OAuth device code flow)
  2. Link your accounts at twitch.tv/drops/campaigns
  3. The miner will automatically discover campaigns and start mining
  4. Configure priority games in Settings to focus on what you want
  5. Monitor progress in the Main and Inventory tabs

Features

  • Stream-less drop mining - saves bandwidth
  • Game priority and exclusion lists
  • Tracks up to 199 channels simultaneously
  • Automatic channel switching
  • Real-time progress tracking

Important Notes

  • Do not watch streams on the same account while mining
  • Keep your cookies.jar file secure
  • Requires linked game accounts for drops

Discord Webhook

Get notified in Discord when drops are claimed or channel points are earned.

  1. Go to your Discord server → Channel Settings → Integrations → Webhooks → New Webhook
  2. Copy the webhook URL
  3. Paste it into Settings → Discord Notifications (separate URLs for drops and points)
  4. Use Test Webhook to verify it works

Discord Bot

Control your miner directly from Discord using slash commands. The bot syncs live stats and can post automatic drop notifications.

Setup

  1. Go to Settings → Discord Bot and click Generate code
  2. Note your dashboard URL (e.g. http://your-server:8081) and the code (e.g. DROPS-A1B2C3D4)
  3. In Discord, run: /link http://your-server:8081 DROPS-A1B2C3D4
  4. The bot confirms: ✅ Connected

Commands

  • /link <url> <code> — connect to your dashboard
  • /dashboard — post a live-updating embed with control buttons (pause, campaigns, drops)
  • /setchannel drops — send drop notifications to this channel
  • /setchannel points — send channel points notifications to this channel
  • /unlink — disconnect the bot

Note: The pairing code expires in 10 minutes. Generate a new one if it expires. To rename your profile (shown in bot footer), go to System → Accounts and use the ✏️ button.
