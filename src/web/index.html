Getting Started

Twitch Drops Miner automatically earns timed Twitch drops without downloading any stream video — saving bandwidth while collecting rewards 24/7.

1
Log in with Twitch

Click Login in the Main tab. A device code appears — open the link, enter the code on Twitch, then return here. Uses OAuth device flow; your password is never stored.

2
Link game accounts

Visit twitch.tv/drops/campaigns and connect each game's account (Steam, Epic, etc.) to your Twitch profile. Drops won't be delivered without this step.

3
Configure priority games (optional)

Open Settings → Priority Games and add games you want to target first. The miner works all campaigns by default if no priority list is set.

4
Watch it run

The Main tab shows the active channel, current drop progress, and live channel points balance. The Inventory tab tracks all claimed drops.

ℹ️
No stream video is downloaded. The miner sends only the minimal Twitch API heartbeats needed to accumulate watch time — bandwidth usage is negligible.
⛏️

Drop Mining

How It Works

The miner discovers all active drop campaigns via the Twitch API, picks a live channel that qualifies for each drop, and sends periodic watch-time signals. No video is ever buffered or downloaded.

Auto Channel Switching

If the current channel goes offline, ends the drop window, or loses drop eligibility, the miner automatically switches to the next best channel — no intervention needed.

Game Priority Queue

Add games to Settings → Priority Games. Games appear in order — the miner finishes the first game's drops before moving to the next. Unlisted games are queued after all priority games.

Drop Name Blacklist

In Settings → Blacklist you can exclude specific drop names (e.g. duplicates you already own). The miner skips any drop whose name matches an entry in the list.

Manual Controls

Inventory & Campaign Drops

The Inventory tab shows all campaigns as cards in a 3-column grid.

  • Click a campaign name → popup showing all drops with images, progress bars, and status
  • Click ▸ N drops left → same popup filtered to unclaimed drops only (only shown for linked campaigns)
  • ⛏ Farming / ⊘ Skip toggle → add or remove the game from your watch list without going to Settings
  • Expired or fully-claimed games are automatically removed from the Wanted Queue
⚠️
Do not watch streams on the same Twitch account while mining. Twitch only counts watch time from one source at a time.

Multi-Account

Run unlimited Twitch accounts simultaneously, each with fully isolated data, settings, and sessions.

➕
Go to System → Instances to add or remove accounts from the dashboard — no config files needed. Nginx updates automatically.
InstancePortURL
Account 18080/
Account 28082/acc2/
Account N8080+(N-1)×2/accN/

The account buttons in the top header show the actual Twitch username once logged in. Each instance has its own:

  • Cookie/session storage
  • Priority games and blacklist
  • Discord bot/webhook settings
  • Channel Points history
  • Idle watch channel list
⚠️
Running 3+ instances on one IP may cause Twitch to flag the accounts. Use proxies if you run more than 2 accounts.
💡
To rename an account label shown in the header and Discord bot footer, go to System → Accounts and click the ✏️ edit button next to the account.

Channel Points

While the miner watches a channel, it also earns and tracks Channel Points automatically.

Auto-Claim Bonus Chests

When a bonus chest appears on a watched channel, the miner claims it immediately. No manual interaction required.

Live Balance

Your current point balance for the active channel is shown in real time at the top of the Main tab.

Full History

The Channel Points tab lists every earn/spend event across all watched channels with timestamps and amounts.

Idle Watch Points

Points are also earned while Idle Watch is active (even when no drops are available), so watching keeps accumulating value.

Idle Watch

When no active drop campaigns are running, Idle Watch keeps the miner watching channels so you continue earning Channel Points.

Configuration

SettingDescription
Manual channel list Add specific channel names in Settings → Idle Watch. The miner rotates through these when idle.
Auto: use followed channels Enable this toggle to automatically fetch your live followed channels from Twitch and watch whichever are currently streaming.

Quick Controls

The Quick Controls panel in the Main tab shows Start Idle and Switch Channel buttons when Idle Watch is active, letting you manage it without navigating to Settings.

💡
Idle Watch is automatically paused when a drop campaign becomes available and resumes when mining finishes.

Discord Bot

Control your miner and receive live notifications directly from Discord. Supports multiple servers simultaneously.

Setup

1
Generate a pairing code

Go to Settings → Discord Bot and click Generate code. A code like DROPS-A1B2C3D4 is shown (valid for 10 minutes).

2
Link from Discord

In any Discord server or DM where the bot is present, run:

/link http://your-server:8080 DROPS-A1B2C3D4

The bot replies with ✅ Connected when the link is established.

3
Set notification channels (optional)

Run /setchannel drops and/or /setchannel points in the channels where you want alerts sent.

Commands

CommandDescription
/link <url> <code>Connect this Discord server to your dashboard instance
/unlinkDisconnect the bot from this server
/setchannel dropsSend drop claim notifications to the current channel
/setchannel pointsSend Channel Points notifications to the current channel
/dashboardPost a live embed showing miner status (auto-updates every 30 s)
ℹ️
The account name shown in the bot embed footer comes from System → Accounts. Use the ✏️ button to rename it. The pairing code expires in 10 minutes — generate a new one if it times out.
🔔

Discord Webhook

A simpler alternative to the bot — paste a webhook URL and get push notifications for drops and/or channel points without any bot setup.

1
Create a webhook in Discord

Server Settings → Integrations → Webhooks → New Webhook. Copy the URL.

2
Paste the URL in Settings

Go to Settings → Discord Notifications. There are separate URL fields for Drop notifications and Channel Points notifications — you can use the same or different webhooks.

3
Test it

Click Test Webhook to send a sample message and confirm delivery.

ℹ️
Webhook notifications include the account name in the footer so you can tell which instance claimed a drop when running multiple accounts.

Remote Access

To use the Discord Bot or access the dashboard from outside your network, your TDM instance needs a public URL. Choose the method that fits your setup.

Ports

InstancePort
Account 18080
Account 28082

Works on any machine — home PC, VPS, laptop. No router config, no open ports. Cloudflare gives you a free HTTPS URL instantly.

1 — Install cloudflared
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cloudflared.deb && sudo dpkg -i cloudflared.deb
brew install cloudflared
winget install Cloudflare.cloudflared
2 — Start tunnel (Account 1)
cloudflared tunnel --url http://localhost:8080

Cloudflare prints a URL like https://random-name.trycloudflare.com — use that as your public URL.

3 — Link Discord Bot

In your Discord server, run:
/link https://random-name.trycloudflare.com YOUR_CODE

⚠ Free Cloudflare URLs change every restart. For a permanent URL, create a free Cloudflare account and set up a named tunnel.

If you're running on a VPS (Hetzner, DigitalOcean, etc.), open the port in UFW and access via your server IP.

# Allow port 8080 (TCP only) sudo ufw allow 8080/tcp sudo ufw reload # Check it's open sudo ufw status

Access via http://YOUR-SERVER-IP:8080. Set a password (see below) — never expose without one.

For a clean domain + HTTPS on a VPS. Install nginx, then add a site config:

server { listen 80; server_name drops.yourdomain.com; location / { proxy_pass http://127.0.0.1:8080; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; proxy_set_header Host $host; } }

Then run sudo certbot --nginx -d drops.yourdomain.com for free HTTPS.

Always set a password when exposing publicly. Set WEB_PASSWORD before starting:

WEB_PASSWORD=mysecretpassword python main.py # or with PM2: TDM_PORT=8080 WEB_PASSWORD=mysecretpassword pm2 start main.py --name twitchdrops --interpreter python3

Sessions last 30 days via secure cookie. Change the password anytime in Settings → System → Login & Password.

Tips & Tricks

Force a campaign refresh

Click Check for Drops in the Main tab to immediately re-fetch campaigns from Twitch without restarting the process.

Restart safely

Use System → Restart Miner. If you're using PM2, it will restart automatically and resume mining within seconds.

Linked accounts required

Drops are only delivered if your game account is linked at twitch.tv/drops/campaigns. Check this first if drops aren't appearing in-game.

Account management

Add, remove, or rename accounts in System → Accounts. Labels appear in the header buttons, Discord bot footer, and webhook notifications.
